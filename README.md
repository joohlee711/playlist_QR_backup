## 새 플레이리스트 올리기

아래 틀을 복사해서 Claude한테 보내고, **콜론(:) 뒤를 전부 채워요.**
빈칸을 남기면 Claude가 물어봐요.

```
새 플리 추가해줘.

스포티파이 링크:
인스타 게시물 링크:
게시 날짜:
플리 제목:
큐레이터:

[캡션]


[곡 코멘트]

```

### 채운 예시

```
새 플리 추가해줘.

스포티파이 링크: https://open.spotify.com/playlist/7i8PotqqlAb88Bwybh7PAk
인스타 게시물 링크: https://www.instagram.com/p/ABC123/
게시 날짜: 2026-11-25
플리 제목: 왼손잡이 덥스텝
큐레이터: Mono Lens (@mono_lens_)

[캡션]
이번에 소개할 음악은 아티스트 Mono Lens가 고른 '왼손잡이 덥스텝' 플레이리스트입니다. …

[곡 코멘트]
Left Hand Path - (코멘트 내용)
Whistle - (코멘트 내용) — Sejung
```

- **큐레이터:** 에디터가 고른 플리면 `Editor's playlist`라고 써요.
- **캡션:** 인스타 캡션 본문을 복붙해요. 맨 아래 트랙리스트(❋ 표시)는 빼도 돼요.
- **곡 코멘트:** 인스타 슬라이드에 들어간 글이에요. 곡 제목을 앞에 붙여주면 정확해요.
  원고 텍스트를 복붙하는 게 제일 좋고, **스크린샷을 첨부**해도 Claude가 읽어서 옮겨줘요 (그때는 오타 한 번 확인해 주세요).
  코멘트 쓴 사람이 따로 있으면 끝에 `— 이름`을 붙여요. 코멘트 없는 곡은 안 써도 돼요.
- 곡 제목·아티스트·커버·QR은 스포티파이에서 자동으로 가져와요.

Claude가 다 넣고 나면 **미리보기**를 보여줘요. 확인하고

> 좋아, 올려줘

라고 하면 사이트에 올라가요. **1~2분 뒤** 사이트에 반영돼요.

## 안 될 때

- **실수로 잘못 올렸어요** → 걱정 마세요. 이렇게 말하면 바로 전 상태로 돌아가요.
  > 방금 올린 거 취소해줘.

  이전 기록이 다 남아 있어서, 더 예전 걸 되돌리는 것도 가능해요 ("어제 올린 거 취소해줘").
- **"올려줘" 했는데 권한 없다고 나와요** → GitHub 초대를 수락했는지 확인하고, Claude한테 "GitHub 로그인 다시 해줘"라고 해요.
- **올렸는데 사이트가 그대로예요** → 2~3분 기다렸다가 새로고침. 그래도 안 바뀌면 Claude한테 "사이트 반영 안 됐어, 확인해줘".
- **곡 정보를 못 가져온대요** → 스포티파이 페이지 구조가 바뀌었을 수 있어요. Claude한테 그대로 말하면 고쳐보거나 레포 주인한테 알려줄 내용을 정리해줘요.
- 그 밖에 뭐든 → 화면 캡처해서 Claude한테 "이거 왜 이래?"
