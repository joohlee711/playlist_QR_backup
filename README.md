# akks playlist archive

akks 인스타그램에 올린 플레이리스트를 모아 보는 사이트예요.

**사이트 주소:** https://joohlee711.github.io/playlist_QR_backup/

모든 작업은 **Claude 데스크톱 앱의 Code 탭**에서 Claude한테 말로 시키면 돼요.
파일을 직접 열거나 고칠 필요는 없어요.

---

## 처음 한 번만 하는 준비

1. **GitHub 초대 수락**
   레포 주인이 보낸 초대 메일(또는 github.com 알림)에서 *Accept invitation*을 눌러요.
   이걸 해야 사이트에 글을 올릴 수 있어요.

2. **Claude 데스크톱 앱 설치 → Code 탭 열기**
   작업할 폴더를 고르라고 하면 *문서* 폴더처럼 아무 데나 골라도 돼요.

3. **Claude한테 이렇게 말하기**
   > https://github.com/joohlee711/playlist_QR_backup 이 레포를 내 컴퓨터에 받아서 작업할 수 있게 준비해줘.

   필요한 프로그램(git, Python 등)이 없으면 Claude가 설치 방법을 알려주거나 직접 설치해요.
   중간에 **GitHub 로그인 창**이 뜨면 로그인하면 돼요.

4. 다음부터는 Code 탭에서 받아둔 `playlist_QR_backup` 폴더를 열고 시작하면 돼요.

## 새 플레이리스트 올리기

아래 내용을 Claude한테 그대로 붙여넣고 빈칸만 채워요.

```
새 플리 추가해줘.

스포티파이 링크:
인스타 게시물 링크:
게시 날짜: 2026-12-01
플리 제목: 왼손잡이 덥스텝
큐레이터: Mono Lens (@mono_lens_)        ← 에디터 플리면 "Editor's playlist"라고 쓰기

[캡션]
(인스타 캡션 본문 복붙. 맨 아래 트랙리스트는 빼도 돼요)

[곡 코멘트]
1. (1번 곡 코멘트) — 쓴 사람 (있으면)
2. (2번 곡 코멘트)
...
```

- 곡 코멘트는 인스타 슬라이드에 들어간 글이에요. 원고 텍스트를 복붙하는 게 제일 정확해요.
  **스크린샷을 첨부**해도 Claude가 읽어서 옮겨줘요 (그때는 오타 한 번 확인해 주세요).
- 코멘트 없는 곡은 비워두면 돼요.
- 곡 제목·아티스트·커버·QR은 스포티파이에서 자동으로 가져와요.

Claude가 다 넣고 나면 **미리보기**를 띄워줘요. 확인하고
> 좋아, 올려줘

라고 하면 사이트에 올라가요. **1~2분 뒤** 사이트에 반영돼요.

## 안 될 때

- **"올려줘" 했는데 권한 없다고 나와요** → GitHub 초대를 수락했는지 확인하고, Claude한테 "GitHub 로그인 다시 해줘"라고 해요.
- **올렸는데 사이트가 그대로예요** → 2~3분 기다렸다가 새로고침. 그래도 안 바뀌면 Claude한테 "사이트 반영 안 됐어, 확인해줘".
- **곡 정보를 못 가져온대요** → 스포티파이 페이지 구조가 바뀌었을 수 있어요. Claude한테 그대로 말하면 고쳐보거나 레포 주인한테 알려줄 내용을 정리해줘요.
- 그 밖에 뭐든 → 화면 캡처해서 Claude한테 "이거 왜 이래?"
